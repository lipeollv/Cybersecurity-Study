Viabilidade técnica:
 Software:
  O aplicativo é projetado com uma arquitetura leve e otimizações de códigos para conseguir garantir compatibilidade com celulares de entrada/antigos (Android), que são os mais usados normalmente.

 Hardware:
  Utilização de hardwares e componentes de custo baixo. A simulação pelo próprio aplicativo já pode ser bastante integratória sem o kit físico em mãos, caso não tenha condições de ter o hardware.

 Infraestrutura e Redes:
  Sincronização de dados mesmo com o dispositivo offline para conseguir acessar as atividades sem uma conexão em rede, porém para o sistema dos pais e professores receberem os dados dos alunos, assim que conectar em uma rede, são enviados automáticamente.
