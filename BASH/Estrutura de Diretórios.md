/  - é a raiz, a base inicial onde tudo começa.

/bin - é aonde fica salvo os comandos essenciais do terminal de um usuário. (um invasor teria interesse nessa pasta para saber quais códigos ele pode digitar que estão dentro da máquina)

/boot - é onde ficam os arquivos necessários para a inicialização do sistema.(um invasor pode modificar o kernel do sistema ou crashar a inicialização do usuário)

/dev - onde ficam os arquivos de dispositivos (hardware).

/etc - todos os arquivos de configurações, ficam dentro dessa pasta. (um invasor pode usar a pasta para chegar em algum arquivo de programa importante e mudar seus dados)

/home - é o diretório pessoal do usuário, onde ficam salvos todos os arquivos pessoas. (um invasor pode roubar dados dos usuários)

/lib - onde fica salvo as configurações dos programas

/mnt - onde você monta arquivos temporários 

/media - onde ficam as médias removíveis (pendrive, hd externo)

/opt - onde são salvos os arquivos de programas opcionais, que o usuário não quer sujar o sistema com eles.

/proc - fornece informações de processo do KERNEL

/root - é o home do root

/run - informações do sistema em execução 

/sbin - são programas (binários) que só podem ser executados pelo root (administrador), binários essenciais do sistema.

/srv - dados específicos de serviços do sistema. (como servidores)

/sys - contém informações relacionadas aos dispositivos conectados ao kernel.

/tmp - armazena arquivos temporários 

/usr - hierarquia secundária, onde salva arquivos de usuários diferentes

/var - arquivos variáveis
